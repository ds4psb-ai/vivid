## 2. 문제점 분석

### 2.1 정보 과부하 (Information Overload)

| 섹션 | 요소 수 | 문제 |
|------|---------|------|
| **LEFT: IP 정보** | 썸네일+제목+장르(3~5)+통계(2) | 중간 |
| **LEFT: 워크플로우** | 카드 2~6개 (각 아이콘+제목+설명+배지) | **높음** |
| **LEFT: 세계관** | 로그라인+배경+에피소드+테마(4~6)+캐릭터(2~4개×6필드) | **매우 높음** |
| **RIGHT: 추천** | 토글3개+배지5개+Evidence카드+대안카드2개+피드백버튼 | **매우 높음** |

**핵심 문제**: 사용자가 "생성하기" 버튼에 도달하기 전에 너무 많은 정보를 소화해야 함.

### 2.2 시각적 계층 혼란

```
현재 상태:
├── 비디오 (시선 집중점 1)
├── IP 헤더 (시선 집중점 2)
├── 워크플로우 카드 (CTA 역할? 정보 역할?)  ← 모호
├── 세계관 (읽기 콘텐츠)
└── 사이드바
    ├── 프리셋 (CTA 1)
    ├── 추천 도구 (정보? CTA?)  ← 모호
    ├── 프롬프트 (입력)
    └── 생성 버튼 (CTA 2)

문제: "워크플로우 카드"와 "생성하기 버튼"이 경쟁 관계
```

### 2.3 우측 사이드바 복잡도

**현재 우측 사이드바 요소 (20개 이상):**

1. 헤더 섹션
   - 아이콘 + 제목
   - 설명 텍스트

2. 프리셋 선택
   - 각 프리셋: 이름 + 체크마크 + 크레딧 + 시간

3. 추천 도구 섹션 (가장 복잡)
   - "추천 도구" 레이블
   - "추천 숨기기" 토글
   - "왜?" 토글
   - "워크플로우 추천됨" 배지
   - "IP 컨텍스트 사용됨" 배지
   - "trace_id 복사" 버튼
   - "추천 차원" 배지들
   - "총 크레딧" 표시
   - Evidence Card (접이식)
   - 피드백 버튼 2개 (👍👎)
   - 대안 추천 카드 2개

4. 프롬프트 입력
   - 레이블 + 텍스트영역

5. 예상
   - 크레딧 + 시간

6. 생성 버튼

**문제**: 개발자/파워유저용 디버깅 UI가 일반 사용자에게 노출됨

### 2.4 중복 CTA 경쟁

| CTA | 위치 | 액션 |
|-----|------|------|
| 워크플로우 카드 | 좌측 | 특정 워크플로우로 직접 이동 |
| 프리셋 선택 | 우측 | 프리셋 선택 |
| 추천 도구 카드 | 우측 | 도구 페이지로 이동 |
| 생성하기 버튼 | 우측 하단 | 워크플로우 모달 표시 |

**사용자 혼란**: "워크플로우 카드를 클릭해야 하나, 생성하기를 눌러야 하나?"

## 3. 사용자 여정 분석

### 3.1 현재 여정 (As-Is)

```
1. 갤러리에서 IP 카드 클릭
2. 상세 페이지 진입
3. 비디오 시청 (자동재생)
4. 스크롤하며 정보 탐색
   → 워크플로우 카드 발견 → 클릭? 아니면 계속 스크롤?
   → 세계관 읽기
   → 캐릭터 정보 읽기
5. 우측 사이드바 확인
   → 프리셋 선택 (이미 선택됨)
   → 추천 도구 섹션 (복잡, 스킵?)
   → 프롬프트 입력 (선택)
6. 생성하기 클릭
7. 워크플로우 모달 표시
8. 모달에서 시작 클릭
9. Reference Decoder 페이지로 이동

→ 총 9단계, 의사결정 포인트 4개
```

### 3.2 이상적 여정 (To-Be)

```
1. 갤러리에서 IP 카드 클릭
2. 상세 페이지 진입
3. 비디오 시청 + 핵심 정보 확인
4. 워크플로우 선택 (명확한 CTA)
5. 워크플로우 시작

→ 총 5단계, 의사결정 포인트 1개
```

## 4. 개선 제안 (가설)

### 4.1 Option A: 탭 기반 정보 분리

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ [비디오 플레이어]                                                           │
├─────────────────────────────────────────────────────────────────────────────┤
│ [탭: 개요] [탭: 세계관] [탭: 캐릭터]                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│ 개요 탭 내용:                                                               │
│ - 제목 + 설명 (2줄)                                                         │
│ - 워크플로우 카드 (주요 CTA)                                                │
│ - "더 알아보기" → 세계관/캐릭터 탭                                          │
└─────────────────────────────────────────────────────────────────────────────┘

장점: 정보 과부하 해소, 관심 있는 사용자만 세계관 탐색
단점: 탭 전환 추가 클릭, 모바일 복잡도
```

```

│ [비디오 플레이어]                                                           │

├─────────────────────────────────────────────────────────────────────────────┤
│ ┌─────────────────────────────────────────────────────────────────────────┐ │
│ │ [🎬 레퍼런스 분석으로 시작하기]  ← 주요 CTA                              │ │
│ │ Reference Decoder → Abyss Mirror → ...                                  │ │

│ 세계관 더보기 (접힘) ▼                                                      │
└─────────────────────────────────────────────────────────────────────────────┘

장점: 명확한 단일 CTA, 빠른 전환
단점: 프리셋/프롬프트 입력 기회 감소
```

### 4.3 Option C: 사이드바 단순화 (권장)

```
우측 사이드바 개선안:

현재 (20+ 요소)                    제안 (8 요소)
──────────────────                 ──────────────────
AI 콘텐츠 생성 헤더                워크플로우 선택 (드롭다운)
프리셋 선택 (2~3개)                ─────────────────
추천 도구 (복잡)          →        프롬프트 입력 (선택)
프롬프트 입력                      ─────────────────
예상                               예상 (간략)
생성하기 버튼                      [시작하기] CTA
                                   ─────────────────
                                   고급 옵션 ▼ (접힘)
                                   - 프리셋 상세
                                   - 추천 도구 (개발자용)
```

### 4.4 Option D: 2-Phase 접근

**Phase 1 (즉시 적용):**
- 세계관 섹션 접힘 처리 (기본 숨김)
- 추천 도구 섹션 기본 숨김 (개발자 모드)
- 프리셋 선택 → 드롭다운 변경

**Phase 2 (리디자인):**
- 좌측/우측 레이아웃 → 단일 컬럼 재설계
- 워크플로우 카드를 히어로 CTA로 승격
- 모바일 최적화

## 5. 질문 리스트 (컨설팅용)

### 5.1 전략적 질문

1. **주요 사용자 페르소나는 누구인가?**
   - 콘텐츠 크리에이터 (빠른 생성 원함)
   - IP 탐색자 (세계관 몰입 원함)
   - 개발자/파워유저 (상세 제어 원함)

2. **핵심 전환 목표는?**
   - IP 상세 → 워크플로우 시작
   - IP 상세 → 세계관 탐색
   - IP 상세 → 구매/구독

3. **모바일 트래픽 비율은?**
   - 현재 레이아웃은 데스크톱 최적화

### 5.2 UX 질문

1. 세계관 섹션이 전환율에 기여하는가, 방해하는가?
2. 추천 도구 섹션이 신뢰도를 높이는가, 혼란을 주는가?
3. 프리셋 선택이 필수인가, 선택인가?
4. 비디오 자동재생이 긍정적 경험인가?

### 5.3 데이터 요청

- 각 섹션별 스크롤 도달률
- 워크플로우 카드 vs 생성하기 버튼 클릭률
- 세계관 섹션 체류 시간
- 추천 도구 토글 사용률
