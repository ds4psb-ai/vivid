## Human Cloud 워크플로우

```
1. 요청: "봉준호 스타일 광고 30초"
        ▼
2. 매칭: 크리에이터 + 도구 조합 추천
        ▼
3. 제작: 도구 활용 + Veo/Sora 생성
        ▼
4. 납품: 저작권 = 요청자
        수익: 크리에이터 75% / 플랫폼 25%
```

## NotebookLM RAG 통합

### 데이터 소스

| 소스 | 활용 |
|------|------|
| 거장 패턴 (봉/박/나) | 스타일 추천 |

1. **입력값 추천**: 도구 실행 시 최적 파라미터 제안
2. **도구 조합 추천**: 노드 형태로 워크플로우 제안
3. **품질 예측**: 설정값 기반 결과 품질 예측

## 특이점 (Singularity) - 템플릿 갤러리

> **Updated**: 2026-01-05

차원 여행자들의 워크플로우가 수렴하는 곳. 여러 차원을 관통한 완성형 템플릿을 탐색하고 적용할 수 있습니다.

### 핵심 특징

| 항목 | 설명 |
|------|------|
| **차원 조합 표시** | 단일 차원이 아닌 `1D→2D→3D` 형태의 워크플로우 흐름 시각화 |
| **태그 기반 필터** | #콘텐츠, #마케팅, #스토리 등 용도별 필터링 |
| **추천 템플릿** | 검증된 워크플로우 우선 노출 |

### API

```
/api/v1/singularity/
├── templates              # 템플릿 목록 (GET)
├── templates/{id}         # 템플릿 상세 (GET)
├── templates/{id}/use     # 템플릿 적용 (POST)
├── templates/{id}/rate    # 템플릿 평가 (POST)
└── seed                   # 시드 데이터 생성 (POST, dev)
```

### UI 경로

- 프론트엔드: `/singularity`
- 사이드바 라벨: "특이점"
