# 14_CODEX_WORKFLOW.md

> Codex 운영 규칙 - Auto Research Mode (2026)

---

## 목적
- Codex 사용 시 **요청마다 최신 정보 검증**을 기본값으로 설정
- MCP 리서치 + 웹서칭을 통해 최신/정확성 확보
- 예외 케이스는 명시하고, 응답에 투명하게 표시

---

## Auto Research Mode (2026)

사용자 입력이 다음 조건을 충족하면 **2026년 기준 MCP 리서치 및 웹서칭** 수행:
- 새로운 기능 구현 요청
- 아키텍처/설계 관련 질문
- 라이브러리/프레임워크 관련 질문

### 예외 (리서치 없이 바로 수행)
- 단순 질문 (무엇인가요?, 어떻게?)
- 간단 패치/수정 요청
- 파일 읽기/탐색 요청
- git 명령어

### 암묵적 예외 (에이전트가 추론 가능)
- 직전 맥락에서 이미 충분히 검증된 사실을 반복 확인하는 경우
- 변경 가능성이 낮고, 로컬 파일만으로 결정 가능한 경우
- 순수 로컬 디버깅/리팩터링(외부 정보 불필요)

---

## 실행 프로토콜
1) 요청 분류: **리서치 필요/불필요** 판단  
2) 리서치 필요 시: MCP 리서치 + 웹서칭 수행  
3) 응답 시: 근거 요약 + 핵심 출처 표시  
4) 리서치 생략 시: **“리서치 생략: <사유>”** 1줄로 명시
