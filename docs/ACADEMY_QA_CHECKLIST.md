# Academy E2E QA Checklist

> 영상 업로드 → 빌더 → 파서 → 최종 프롬프트 전체 플로우 검증 기준

---

## STEP 1-2: 영상 업로드 + 씬 감지

### 씬 감지 결과 검증
| 항목 | 기준 | PASS/FAIL |
|------|------|-----------|
| 타임스탬프 포맷 | `MM:SS.ss` (예: `00:01.67`) | |
| 첫 프레임 포함 | `00:00.00` 항상 첫 번째 | |
| 씬 수 합리성 | 30초 영상 → 5~15씬 (standard), 10~25씬 (precise) | |
| 진행률 표시 | 업로드 0~100% → "씬 분석 중" 전환 | |
| 모드 전환 | "정밀 모드로 다시 분석" 클릭 → 실제 threshold 변경 확인 | |

### 프레임 다운로드 검증
| 항목 | 기준 |
|------|------|
| ZIP 구조 | `timestamps.txt` + `frames/frame_01_*.jpg, frame_02_*.jpg...` |
| 프레임 매칭 | 각 프레임이 해당 타임스탬프 시점과 일치 |
| 파일명 패턴 | `frame_{nn}_{MM-SS.ss}.jpg` |

## STEP 3: 빌더 (AI Studio 통합빌더)

### 오마쥬 MD 검증

#### 구조 체크
| 항목 | 기준 | PASS/FAIL |
|------|------|-----------|
| 앵커 섹션 | `## ⭐ 앵커 이미지 먼저 생성` 존재 | |
| 씬 헤더 | `## 📍 Scene XX: [제목] (MM:SS.ss~MM:SS.ss)` | |
| IMAGE 섹션 | `### 🖼️ IMAGE` 각 씬마다 존재 | |
| MOTION 섹션 | `### 🎥 MOTION` 각 씬마다 존재 | |
| [REF] 태그 | `[REF: COMP=scene_XX.png, FACE=...]` 각 씬마다 존재 | |
| [COPY] 마커 | `[📋 COPY]` NanoBanana/MJ/Kling/Veo 각각 존재 | |
| 코드블록 | 모든 프롬프트가 ``` 코드블록 안에 | |

#### 앵커 검증
| 항목 | 기준 |
|------|------|
| 앵커 씬 FACE | `FACE=NONE` (자기참조) |
| 비앵커 씬 FACE | `FACE=MALE_ANCHOR` 또는 `FEMALE_ANCHOR` 또는 `BOTH` |
| 앵커 캐릭터 묘사 | 인종, 의상, 외모 등 구체적 |

#### IMAGE 프롬프트 체크
| 도구 | 검증 기준 |
|------|-----------|
| **NanoBanana** | 한글, 5줄 이상, 환경/인물/조명/구도/분위기 포함 |
| **Midjourney V7** | 영어, `--ar 9:16`, `--v 7`, `--style raw` 필수 |
| **MJ 비앵커** | `--oref [URL]` + `--ow 30~250` 포함 |
| **MJ --ow 범위** | 클로즈업: 150-250, 미디엄: 80-150, 와이드: 30-80 |
| **MJ --stylize** | Phase 1-2: 250-300, Phase 3-4: 100-150 |
| **MJ --no** | 씬 상태 기반 네거티브 (예: 서있으면 `--no sitting`) |

#### MOTION 프롬프트 체크
| 도구 | 검증 기준 |
|------|-----------|
| **Kling 3.0** | 영어, 35 words 이하, `[동작]. [마이크로모션]. Audio: "[환경음]. [효과음]."` |
| **Veo 3.1** | 영어, 50-100 words, `Cinematography:` + `Action:` + `Audio:` 3슬롯 |
| **Veo Action** | `within first second` 패턴 포함 |

#### ANTI-LAZY 검증 (필수!)
| 패턴 | 감지 시 FAIL |
|------|-------------|
| `위와 동일` | 모든 씬이 개별 작성되어야 함 |
| `이하 생략` | 생략 없이 전체 작성 |
| `similar to Scene` | 영어 생략도 불가 |
| `같은 방식으로` | 반복이라도 풀네임 작성 |
| `(생략)` / `(skip)` | 어떤 형태의 생략도 불가 |
| `...` (말줄임) | 프롬프트 내 생략 표시 불가 |

### 변주 MD 검증

#### 변주 타입 확인
| 타입 | 변경 범위 | 고정 비율 |
|------|-----------|-----------|
| **A (Stable)** | 소품만 변경, 인물 동일 | 92% 고정 |
| **B (Balanced)** | 의상 + 소품 + 조명톤 | 85% 고정 |
| **C (Aggressive)** | 문화/스타일 전체 변환 | 82% 고정 |

#### 변주 고정 변수 (반드시 유지)
- 타이밍 (컷 길이, 전환 타이밍)
- 구도 (소실점, 3분할, 피사체 위치)
- 카메라 (앵글, 프레이밍, 줌 방향)
- 조명 (색온도, 그림자 방향)
- 모션 타이밍 ("IMMEDIATELY" 패턴)

#### 변주 구조 체크
| 항목 | 기준 |
|------|------|
| 전체 재작성 | 오마쥬와 동일 구조로 전체 재작성 (축약 없음) |
| 앵커 재생성 | 변주용 앵커도 새로 작성 |
| [REF] 태그 유지 | 변주에도 [REF] 태그 포함 |
| 씬 수 동일 | 오마쥬와 동일한 씬 수 |

## STEP 4: 파서 검증

### 파싱 결과 체크
| 항목 | 기준 | PASS/FAIL |
|------|------|-----------|
| 씬 전체 파싱 | 모든 씬이 SceneCard로 표시 | |
| 오마쥬/변주 탭 | 둘 다 있으면 탭 전환 가능 | |
| 앵커 표시 | 앵커 씬에 배지 표시 | |
| 프롬프트 4개 | 씬당 NB/MJ/Kling/Veo 4개 표시 | |
| 경고 감지 | LAZY 패턴/파라미터 누락 경고 표시 | |
| 복사 기능 | 클릭 → 클립보드에 순수 프롬프트만 복사 (마크다운 없음) | |
| 진행 추적 | 복사할수록 프로그레스바 증가 | |

### 복사된 프롬프트 품질
| 항목 | 기준 |
|------|------|
| 순수 텍스트 | 코드펜스, 라벨, 마크다운 문법 없음 |
| 파라미터 온전 | `--ar`, `--v`, `--oref` 등 잘림 없음 |
| 줄바꿈 유지 | 멀티라인 프롬프트 줄바꿈 보존 |

| 모드 | Temperature | 목적 |
|------|------------|------|
| 오마쥬 | 0.2 | 엄격한 구도/타이밍 재현 |

## MJ V7 파라미터 빠른 참조

| 파라미터 | 용도 | 필수 여부 |
|----------|------|-----------|
| `--ar 9:16` | 세로 숏폼 비율 | 필수 |
| `--v 7` | V7 모델 | 필수 |
| `--style raw` | 실사 스타일 | 필수 |
| `--oref [URL]` | 옴니 레퍼런스 (V7) | 비앵커 씬 필수 |
| `--ow [값]` | 옴니 웨이트 (50-250) | `--oref` 사용시 필수 |
| `--stylize [값]` | 비주얼 라임 강도 | 권장 |
| `--no [키워드]` | 네거티브 프롬프트 | 씬 상태 기반 |
| `--iw 2.0` | 이미지 웨이트 | 구도 앵커 시 |

> **주의**: `--ow > 500` → 품질 저하 경고
> **V7 변경점**: `--cref` → `--oref`, `--cw` → `--ow`

## 체크리스트 사용법

1. 사용자가 오마쥬.md 붙여넣기 → "구조 체크" + "ANTI-LAZY" + "IMAGE/MOTION 프롬프트 체크" 순서로 검증
2. 변주.md 붙여넣기 → "변주 타입 확인" + "고정 변수 유지" + "전체 재작성" 확인
3. 파서 결과 스크린샷 → "파싱 결과 체크" + "복사된 프롬프트 품질" 확인
4. 최종 이미지/영상 결과 → 구도 일치도, 앵커 참조 정확도 평가
