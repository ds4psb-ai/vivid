1. 환경 설정

1.1 Google AI Studio 접속

모든 Builder 도구는 Google AI Studio에서 실행됩니다.

접속 방법: 1. 브라우저에서 aistudio.google.com 접속 2. Google 계정으로 로그인

Canvas 앱 사용 방법: 1. 좌측 패널 상단 “+ 새 앱” 클릭 2. “Canvas App” 선택 3. ZIP 파일 업로드: 제공받은 builder1-hardened.zip 또는 builder2-hardened.zip 업로드 4. 자동으로 앱이 로드됨

⚠️ ZIP 파일 제한: 최대 10개 파일, 100MB 이하

1.2 Antigravity 설치 (선택사항)

Antigravity는 Google의 AI 기반 코딩 어시스턴트입니다. 로컬에서 코드를 수정하거나 확장하려면 설치합니다.

설치 방법: 1. antigravity.google 접속 2. 운영체제에 맞는 설치 파일 다운로드 - macOS: Monterey 12 이상 - Windows: 64-bit Windows 10 이상 3. 설치 마법사 실행 후 Google 계정으로 로그인 4. “Start fresh” 선택 → 다크 테마 추천

1.3 FFmpeg 설치 (프레임 추출용)

macOS (Homebrew 사용):

# Homebrew 업데이트
brew update

# FFmpeg 설치
brew install ffmpeg

# 설치 확인
ffmpeg -version

Windows: 1. ffmpeg.org/download.html 접속 2. Windows 빌드 다운로드 및 압축 해제 3. 환경변수 PATH에 ffmpeg/bin 폴더 추가

2. 첫 프레임 추출 (ANCHOR Image)

2.1 왜 필요한가?

ANCHOR 이미지는 캐릭터 일관성의 기준점입니다. 영상의 첫 프레임(또는 캐릭터가 가장 잘 보이는 프레임)을 추출하여 이후 모든 이미지 생성의 레퍼런스로 사용합니다.

2.2 FFmpeg 명령어

첫 프레임 추출:

ffmpeg -i input_video.mp4 -vf "select=eq(n\,0)" -vframes 1 anchor_frame.png

특정 시간대 프레임 추출 (예: 2.5초 지점):

ffmpeg -i input_video.mp4 -ss 00:00:02.500 -vframes 1 anchor_frame.png

영상 정보 확인:

ffprobe input_video.mp4

2.3 프레임 선택 팁

좋은 ANCHOR 피해야 할 ANCHOR
캐릭터 얼굴이 정면/3/4 각도 뒷모습, 옆모습
조명이 균일함 역광, 극단적 명암
표정이 중립적 과격한 표정
해상도가 선명함 모션 블러, 흔들림

3. Builder 1: 이미지 프롬프트 생성

3.1 개요

Builder 1은 영상을 분석하여 이미지 생성용 프롬프트를 만드는 도구입니다.

출력 형식: - NanoBanana Pro (한글, 기본) - Midjourney V7 (영문, 선택)

3.2 사용 방법

  1. ZIP 파일 업로드: Google AI Studio Canvas에 builder1-hardened.zip 업로드
  2. 영상 파일 업로드: 분석할 영상 첨부
  3. 4-STEP 워크플로우 진행:
STEP 내용 출력
1 영상 분석 씬 테이블 + 캐릭터 프로필 + Visual Rhyme + 구도 분석
2 Phase 1-2 과거/회상 씬 이미지 프롬프트
3 Phase 3-4 현재/결말 씬 이미지 프롬프트
4 최종 출력 RAW 마크다운 (Builder 2 입력용)

4. 바이브 철학관: 자기 데이터셋 생성

4.1 개요

바이브 철학관은 대화를 통해 심층 페르소나 프로필을 생성하는 도구입니다. 생성된 JSON 데이터셋은 Builder 2에서 패러디/변주 생성 시 고도화에 사용됩니다.

4.2 사용 방법

  1. ZIP 파일 업로드: Google AI Studio Canvas에 vibe-philosophy.zip 업로드
  2. 프로필 입력:
    • 이름, 생년월일 (음력/양력)
    • 관상 사진 (드래그 앤 드롭 가능)
    • MBTI (선택)
  3. 세션 시작: “세션 시작” 버튼 클릭
  4. 대화 진행: AI와 자연스럽게 대화하며 심층 분석 진행

4.3 심도 시스템 (6단계)

단계 심도 분석 내용
탐색 0-25% 라포 형성, 기본 정보
전개 26-45% 표면적 고민 확인
잠재의식 46-65% 조건화된 반응 패턴
무의식 66-85% 그림자 분석, 억압된 욕구
원형 86-95% 원형 통합, 집단무의식
합성 96-100% 최종 솔루션 합성

4.4 출력: Digital Twin JSON

50% 이상에서 “영혼 추출” 버튼이 활성화되며, 다음 구조의 JSON을 다운로드할 수 있습니다:

{
  "meta": { "currentDepth": 78, "currentStage": "unconscious" },
  "extracted": {
    "emotionalKeywords": ["그리움", "후회"],
    "topicKeywords": ["가족", "어린시절"],
    "deepSignals": ["인정욕구", "분리불안"]
  },
  "depthAnalysis": {
    "dominantArchetype": "영원한 소년 (Puer Aeternus)",
    "shadowAspects": ["권위에 대한 반발"],
    "attachmentStyle": "불안-회피형"
  }
}

5. Builder 2: 패러디 엔진

5.1 개요

Builder 2는 Builder 1의 출력과 페르소나 데이터를 결합하여 오마쥬/패러디/변주 프롬프트를 생성합니다.

5.2 입력 데이터

필수 선택
원본 영상 페르소나 JSON (철학관 출력)
Builder 1 출력 (마크다운) 베스트 댓글 (최대 5개)

5.3 사용 방법

  1. ZIP 파일 업로드: builder2-hardened.zip 업로드
  2. 입력 데이터 업로드:
    • 영상 파일 드래그 앤 드롭
    • Builder 1 마크다운 파일 드래그 앤 드롭 (또는 붙여넣기)
    • (선택) 페르소나 JSON 파일 드래그 앤 드롭
  3. 4-STEP 워크플로우 진행:
STEP 내용
1 텍스트 재현성 검증
2 오마쥬 프롬프트 생성
3 변주/패러디 프롬프트 생성
4 최종 출력 (RAW 다운로드)

5.4 오마쥬 vs 변주

유형 설명 예시
오마쥬 원본 구도/분위기 유지, 캐릭터만 교체 생일 케이크 씬 → 내 어린시절로
변주/패러디 구도 유지, 상황/맥락 변형 생일 케이크 → 퇴직 케이크

6. 이미지 생성 도구

6.1 NanoBanana Pro (추천)

특징: - 한글 프롬프트 지원 - 4K 이미지 출력 (약 3-8초) - 캐릭터 일관성 우수 - 멀티 이미지 레퍼런스 지원

접속: Google AI Studio 또는 nanobanana-pro.com

사용 순서: 1. 레퍼런스 이미지 업로드 (ANCHOR 이미지) 2. Builder 1/2에서 생성된 한글 프롬프트 붙여넣기 3. Generate 클릭 → 4K 이미지 다운로드

6.2 Midjourney V7 (선택)

특징: - 영문 프롬프트 전용 - 예술적 스타일 강점 - 파라미터 커스터마이징

핵심 파라미터:

--iw 2.0      # 이미지 가중치
--ar 9:16     # 세로 영상 비율
--v 7         # 버전 7
--style raw   # 원본 스타일
--cref [URL]  # 캐릭터 레퍼런스
--stylize 250 # 스타일 강도 (과거 씬)
--stylize 400 # 스타일 강도 (현재 씬)
--no [항목]   # 제외할 요소

7. 영상 생성 도구

7.1 Veo 3.1 (Google)

특징: - 1080p/4K 출력 - 네이티브 오디오 생성 (배경음, 대사, 효과음) - 실사 물리 시뮬레이션 - 텍스트 → 영상 / 이미지 → 영상

접속: Gemini App 또는 gemini.google.com → Flow

사용법: 1. ANCHOR 이미지 + Builder 프롬프트 입력 2. 9:16 (세로) 또는 16:9 (가로) 선택 3. Generate → 영상 다운로드

7.2 Kling AI (Kuaishou)

특징: - 멀티 이미지 레퍼런스 (최대 4장) - 캐릭터 일관성 강점 - 동시 영상+오디오 생성 (2.6 버전)

접속: klingai.com

Canvas 기능: - 여러 장의 이미지에서 캐릭터 특징 추출 - 동적 상호작용 영상 생성
