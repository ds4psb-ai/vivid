# Mixboard 스타일 가이드

## 기본 프롬프트 구조

```
[주체] + [행동/상태] + [장소] + [시간/조명] + [스타일] + [분위기]
```

**예시:**
```
Korean male founder, coding intensely,
in a modern Seoul cafe, 3AM warm light,
cinematic 4K, moody and focused atmosphere
```

---

## 스타일 키워드

### 조명
- `golden hour` - 황금빛 석양
- `blue hour` - 새벽/저녁 푸른빛
- `neon glow` - 네온 조명
- `warm ambient` - 따뜻한 실내광
- `laptop screen glow` - 노트북 화면 빛
- `rain-reflected lights` - 비에 반사된 불빛

### 분위기
- `cinematic` - 영화적
- `moody` - 무드 있는
- `cozy` - 아늑한
- `cyberpunk` - 사이버펑크
- `minimal` - 미니멀
- `dramatic` - 드라마틱
- `ethereal` - 몽환적

### 카메라/구도
- `close-up portrait` - 클로즈업
- `medium shot` - 미디엄샷
- `wide establishing shot` - 와이드
- `over the shoulder` - 어깨 너머
- `low angle` - 로우앵글
- `bird's eye view` - 탑뷰

### 색감
- `warm tones` - 따뜻한 톤
- `cool tones` - 차가운 톤
- `high contrast` - 강한 대비
- `muted colors` - 차분한 색감
- `vibrant` - 선명한

## Mixboard 기능 활용

### Explore (탐색)
- 첫 프롬프트로 20개 변형 생성
- 방향성 확인용
- 마음에 드는 3개 선택

### Expand (확장)
- 선택한 이미지의 캔버스 확장
- 더 넓은 씬 구성
- 좌우/상하 확장 가능

### Refine (다듬기)
- "더 따뜻하게"
- "조명을 왼쪽에서"
- "배경을 더 블러하게"
- 세부 조정용

### Edit (편집)
- 부분 수정
- 오브젝트 추가/제거
- 텍스트 요소 추가
