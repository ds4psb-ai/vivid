>
> 내 영상을 AI로 재탄생시키는 완전 가이드

---

## 이 워크샵에서 배우는 것

| 도구 | 역할 |
|------|------|
| **Builder 1** | 영상 분석 → 이미지 프롬프트 생성 |
| **Builder 2** | 분석 결과 → 오마주/변주 생성 |
| **바이브 철학관** | AI 대화 → 나의 프로필 생성 |
| **NanoBanana / Midjourney** | 이미지 생성 |
| **Veo 3.1 / Kling AI** | 영상 생성 |

---

## 전체 흐름

```
📹 내 영상
    ↓
🔍 Builder 1 (영상 분석기)
    ↓
🎭 Builder 2 (변주 엔진) ←── 🔮 나의 프로필 (선택)
    ↓
🖼️ 이미지 생성
    ↓
🎬 영상 생성
    ↓
✨ 나만의 영상 완성!
```
