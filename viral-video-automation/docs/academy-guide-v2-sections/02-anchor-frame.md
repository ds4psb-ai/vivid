# 🎬 기준 프레임 추출

> 기준 프레임 (ANCHOR) = 모든 이미지 생성의 **기준점**

---

## 왜 필요한가요?

AI가 영상 속 캐릭터를 일관되게 그리려면 **"이 사람이야!"** 하고 알려줄 기준 이미지가 필요해요.

```
기준 프레임 없이 생성 → 매번 다른 얼굴 😵
기준 프레임 사용 → 같은 캐릭터 유지 😊
```

---

## 기준 프레임 추출하기

### 첫 번째 프레임 추출

```bash
ffmpeg -i 내영상.mp4 -vf "select=eq(n\,0)" -vframes 1 기준프레임.png
```

> 영상의 맨 첫 장면을 이미지로 저장해요

---

### 특정 시간대 추출

> 얼굴이 가장 잘 보이는 장면을 찾았다면?

**예시: 2.5초 지점 추출**

```bash
ffmpeg -i 내영상.mp4 -ss 00:00:02.500 -vframes 1 기준프레임.png
```

---

### 영상 정보 확인

```bash
ffprobe 내영상.mp4
```

> 영상 길이, 해상도, 프레임레이트 등 확인

---

## 좋은 기준 프레임 vs 나쁜 기준 프레임

| ✅ 좋은 기준 프레임 | ❌ 피해야 할 기준 프레임 |
|-------------------|----------------------|
| 얼굴이 정면 또는 3/4 각도 | 뒷모습, 옆모습만 보임 |
| 조명이 균일함 | 역광, 극단적 명암 |
| 표정이 자연스러움 | 과격한 표정 (소리 지르기 등) |
| 해상도가 선명함 | 모션 블러, 흔들림 |
