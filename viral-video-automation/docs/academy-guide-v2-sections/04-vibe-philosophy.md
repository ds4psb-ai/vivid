# 🔮 바이브 철학관

> AI와 대화하며 **나의 프로필**을 만들어요

---

## 바이브 철학관이란?

```
💬 AI와 대화
    ↓
🔍 심층 분석 진행
    ↓
💾 나의 프로필 (JSON) 저장
```

저장한 프로필은 Builder 2에서 사용해요
→ **나의 감성이 담긴 변주 영상**을 만들 수 있어요

---

## 시작하기

☐ **Step 1**: AI Studio에서 `vibe-philosophy.zip` 업로드

☐ **Step 2**: 기본 정보 입력

| 필수 | 선택 |
|------|------|
| 이름 | 관상 사진 |
| 생년월일 | MBTI |

☐ **Step 3**: "세션 시작" 클릭

☐ **Step 4**: AI와 자연스럽게 대화

---

## 분석 깊이 시스템

> 대화가 진행될수록 분석이 깊어져요

| 단계 | 깊이 | 내용 |
|------|------|------|
| 🌱 탐색 | 0~25% | 라포 형성, 기본 정보 |
| 🌿 전개 | 26~45% | 표면적 고민 확인 |
| 🌲 잠재의식 | 46~65% | 반응 패턴 분석 |
| 🌳 무의식 | 66~85% | 그림자, 억압된 욕구 |
| 🌴 원형 | 86~95% | 원형 통합 |
| 🏔️ 합성 | 96~100% | 최종 솔루션 |

---

## 프로필 저장하기

> 📌 **50% 이상** 도달하면 "프로필 저장" 버튼이 활성화돼요

☐ 50% 이상 도달 확인

☐ "프로필 저장" 버튼 클릭

☐ JSON 파일 다운로드

---

## 프로필 예시

```json
{
  "분석깊이": 78,
  "현재단계": "무의식",

  "감정키워드": ["그리움", "후회"],
  "주제키워드": ["가족", "어린시절"],
  "깊은신호": ["인정욕구", "분리불안"],

  "원형": "영원한 소년 (Puer Aeternus)",
  "그림자": ["권위에 대한 반발"],
  "애착유형": "불안-회피형"
}
```

---

## 대화 팁

> 💡 솔직하게 대화할수록 프로필이 풍부해져요

### 좋은 예시

✅ "어릴 때 아버지와의 기억이 별로 없어요"

✅ "인정받고 싶은 마음이 강한 것 같아요"

✅ "뭔가 늘 불안한 느낌이 있어요"

### 피해야 할 예시

❌ "그냥 평범해요" (너무 짧음)

❌ "잘 모르겠어요" (회피)

☐ 50% 이상 깊이 도달

☐ 프로필 (JSON) 다운로드 완료
