# 🎭 Builder 2: 변주 엔진

> 분석 결과 + 나의 프로필 → **오마주/변주** 생성

---

## 오마주 vs 변주

| 유형 | 설명 | 예시 |
|------|------|------|
| **오마주** | 원본 존중 | 생일 케이크 씬 → 내 어린시절로 |
| | 구도/분위기 유지, 캐릭터만 교체 | |
| **변주** | 창의적 변형 | 생일 케이크 → 퇴직 케이크 |
| | 구도 유지, 상황/맥락 변형 | |

---

## 입력 데이터

| 필수 | 선택 |
|------|------|
| 📹 원본 영상 | 🔮 나의 프로필 (JSON) |
| 📝 Builder 1 출력 (마크다운) | 💬 베스트 댓글 (최대 5개) |

> 💡 **팁**: 나의 프로필을 넣으면 나의 감성이 반영된 변주가 생성돼요

---

## 시작하기

☐ **Step 1**: AI Studio에서 `builder2-hardened.zip` 업로드

☐ **Step 2**: 입력 데이터 업로드

- 영상 파일 드래그 앤 드롭
- Builder 1 마크다운 드래그 앤 드롭 (또는 붙여넣기)
- (선택) 나의 프로필 JSON 드래그 앤 드롭

☐ **Step 3**: 4단계 워크플로우 진행

---

## 4단계 워크플로우

### STEP 1: 재현성 검증 ✅

> Builder 1 출력이 영상과 일치하는지 확인

- 씬 순서 맞는지?
- 캐릭터 설명 정확한지?
- 시각 대비 분석 맞는지?

---

### STEP 2: 오마주 프롬프트 생성 🎬

> 원본을 존중하는 이미지 프롬프트

**특징:**
- 원본과 동일한 구도
- 원본과 동일한 조명/색감
- 캐릭터만 나(또는 내 가족)로 교체

---

### STEP 3: 변주 프롬프트 생성 🎭

> 나의 프로필을 반영한 창의적 변형 프롬프트

**특징:**
- 기본 구도 유지
- 상황/맥락 변형 (예: 생일→퇴직, 어린시절→현재)
- 나의 감정 키워드 반영

---

### STEP 4: 원본 파일 다운로드 📥

> 이미지/영상 생성에 바로 사용 가능!

---

## 출력 예시

### 오마주 프롬프트

```
거실에서 생일 케이크를 들고 있는 40대 여성.
따뜻한 텅스텐 조명, 세피아 톤.
뒤에 "생일 축하해" 풍선 장식.
7살 남자아이가 생일 모자를 쓰고 환하게 웃고 있다.
정면 미디엄 샷, 따뜻한 가족 분위기.
```

### 변주 프롬프트

```
거실에서 퇴직 케이크를 들고 있는 60대 여성.
부드러운 자연광, 노을 톤.
뒤에 "수고하셨습니다" 현수막.
30대 아들이 정장을 입고 눈시울을 붉히고 있다.
정면 미디엄 샷, 감동적인 가족 분위기.
```
