## 시작하기

☐ **Step 3**: 4단계 워크플로우 진행

---

## 4단계 워크플로우

### STEP 1: 영상 분석 📊

> 영상을 업로드하면 AI가 자동으로 분석해요

**분석 결과:**

| 항목 | 설명 |
|------|------|
| 📊 씬 테이블 | 장면별 시간/내용 정리 |
| 👤 캐릭터 프로필 | 등장인물 특징 |
| 🎨 시각 대비 | 과거↔현재 조명/색감 차이 |
| 📐 구도 분석 | 카메라 앵글, 배치 |

---

### STEP 2: 1막 프롬프트 (과거) 🌅

> 회상/추억 장면의 이미지 프롬프트 생성

**특징:**
- 따뜻한 색감 (세피아, 골드톤)
- 부드러운 조명
- 그레인/빈티지 효과

---

### STEP 3: 2막 프롬프트 (현재) 🌆

> 현재/결말 장면의 이미지 프롬프트 생성

**특징:**
- 선명한 색감 (콜드톤 또는 뉴트럴)
- 깔끔한 조명
- 고해상도 디테일

---

### STEP 4: 원본 파일 다운로드 📥

> 마크다운 파일로 저장

이 파일을 **Builder 2**에 입력으로 사용해요!

---

## 출력 예시

```markdown
## 📊 영상 분석 요약

### 씬 테이블
| Scene | 시간대 | 설명 | 기준 |
|-------|--------|------|------|
| 01 | 00:00~00:01 | 거실에서 케이크 들고 있는 엄마 | ⭐ 기준 프레임 |
| 02 | 00:01~00:02 | 7살 소년의 생일파티 | |
| 03 | 00:02~00:05 | 촛불 끄는 장면 | |

### 캐릭터 프로필
- **엄마**: 40대 여성, 단발머리, 크림색 스웨터
- **아들**: 7세 남아, 생일 모자 착용

### 시각 대비 (Visual Rhyme)
| 1막 (과거) | 2막 (현재) |
|-----------|-----------|
| 따뜻한 텅스텐 조명 | 차가운 형광등 |
| 세피아 톤 | 뉴트럴 톤 |
| 소프트 포커스 | 샤프 포커스 |
```
