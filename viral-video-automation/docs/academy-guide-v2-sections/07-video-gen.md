# Veo 3.1 (Google)

> 🎬 **이미지 → 영상 변환 + 오디오 자동 생성**

---

## 특징

| 항목 | 내용 |
|------|------|
| 해상도 | 1080p / 4K |
| 오디오 | 자동 생성 (배경음, 대사, 효과음) |
| 강점 | 실사 물리 시뮬레이션 |
| 입력 | 텍스트 → 영상 / 이미지 → 영상 |

**접속**: Gemini 앱 → **"Flow" 메뉴**

또는 [gemini.google.com](https://gemini.google.com)

---

## 사용 순서

☐ **Step 1**: Gemini 앱 접속 → "Flow" 메뉴

☐ **Step 2**: 기준 프레임 이미지 업로드

☐ **Step 3**: Builder 프롬프트 입력

☐ **Step 4**: 비율 선택

| 비율 | 용도 |
|------|------|
| 9:16 | 세로 (틱톡, 릴스, 쇼츠) |
| 16:9 | 가로 (유튜브) |
| 1:1 | 정사각형 (인스타그램) |

☐ **Step 5**: Generate → 영상 다운로드

---

# Kling AI (Kuaishou)

> 👥 **멀티 이미지 레퍼런스로 캐릭터 일관성 최고**

---

## 특징

| 항목 | 내용 |
|------|------|
| 레퍼런스 | 최대 4장 동시 참조 |
| 강점 | 캐릭터 일관성 최고 |
| 버전 | 2.6+ (영상+오디오 동시 생성) |

**접속**: [klingai.com](https://klingai.com)

---

## Canvas 기능

> 여러 장의 이미지에서 캐릭터 특징 추출

☐ 기준 프레임 + 추가 참조 이미지 업로드 (최대 4장)

☐ 캐릭터 특징 자동 추출

☐ 일관된 캐릭터로 영상 생성

---

## 사용 순서

☐ **Step 1**: [klingai.com](https://klingai.com) 접속 & 로그인

☐ **Step 2**: "Image to Video" 선택

☐ **Step 3**: 기준 프레임 이미지 업로드

☐ **Step 4**: (선택) Canvas에서 추가 참조 이미지 업로드

☐ **Step 5**: Builder 프롬프트 입력

☐ **Step 6**: Generate → 영상 다운로드

---

## 도구 선택 가이드

| 상황 | 추천 도구 |
|------|----------|
| 오디오(배경음, 대사)까지 필요 | **Veo 3.1** |
| 캐릭터 일관성이 중요 | **Kling AI** |
| 빠른 테스트 | **Veo 3.1** |
| 최고 품질 | **Kling AI** |

---

☐ Builder 프롬프트 준비

☐ 도구 선택 (Veo / Kling)

☐ 비율 선택 (9:16, 16:9, 1:1)

☐ 영상 생성 완료

☐ 결과물 다운로드
