## 🎨 이미지 생성 문제

### ERR-IMG-001: 캐릭터 불일치

**증상**: 씬마다 얼굴이 다름

| 항목 | 내용 |
|------|------|
| **원인** | ANCHOR 미사용 또는 --cw 낮음 |
| **해결책** | 1. ANCHOR 재생성 (MJ --oref) 2. --cw 50-100으로 상향 3. 후속 씬 모두 재생성 |
| **예방** | ANCHOR 먼저 확정 후 진행 |
| **롤백** | `./version.sh rollback images v{이전}` |

---

### ERR-IMG-002: 손/얼굴 왜곡

**증상**: 손가락 6개, 얼굴 뭉개짐

| 항목 | 내용 |
|------|------|
| **원인** | 복잡한 포즈, 해상도 부족 |
| **해결책** | 1. `--no deformed hands, extra fingers` 추가 2. 손 가리는 구도로 변경 3. NanoBanana로 전환 (대화형 수정) |
| **예방** | 템플릿에 기본 negative 포함 |

---

### ERR-IMG-003: 의상/소품 변경

**증상**: 줄무늬 티셔츠가 무지로 변경

| 항목 | 내용 |
|------|------|
| **원인** | Multi-Entity 미적용 |
| **해결책** | 1. 의상 레퍼런스 별도 첨부 2. Kling Elements 3번 슬롯 활용 |
| **예방** | MULTI_ENTITY.md 가이드 준수 |

---

### ERR-IMG-004: 배경 불일치

**증상**: 1990s 아파트가 현대식으로

| 항목 | 내용 |
|------|------|
| **원인** | 배경 레퍼런스 누락 |
| **해결책** | 1. Scene 1에서 배경 추출 2. 이후 씬에 레퍼런스로 첨부 |
| **예방** | 첫 씬에서 배경 확정 |

## 🎬 영상 생성 문제

### ERR-VID-001: 모핑/텔레포트

**증상**: 캐릭터가 순간이동, 얼굴 변형

| 항목 | 내용 |
|------|------|
| **원인** | Creativity 높음, 동작 과다 |
| **해결책** | 1. Creativity 0.5 이하로 2. 1 Camera 1 Action 룰 적용 3. Frame Chaining 적용 |
| **예방** | CRITIQUE_VIDEO.md 체크 |
| **롤백** | `./version.sh rollback videos v{이전}` |

---

### ERR-VID-002: 타이밍 불일치

**증상**: 동작이 너무 빠르거나 느림

| 항목 | 내용 |
|------|------|
| **원인** | Beat Timing 누락 또는 부정확 |
| **해결책** | 1. 원본 영상 타이밍 재확인 2. Beat Timing 패턴 수정 3. 짧은 씬 1초 이상으로 확장 |
| **예방** | ANALYSIS.md 타이밍 정확히 기록 |

---

### ERR-VID-003: 아티팩트/글리치

**증상**: 픽셀 깨짐, 이상한 패턴

| 항목 | 내용 |
|------|------|
| **원인** | 이미지 품질 낮음, 도구 한계 |
| **해결책** | 1. 원본 이미지 해상도 확인 (1080p+) 2. Sora로 도구 변경 3. Motion 값 낮추기 |
| **예방** | 고해상도 이미지 사용 |

---

### ERR-VID-004: 영상 간 점프컷

**증상**: 씬 전환 시 급격한 변화

| 항목 | 내용 |
|------|------|
| **원인** | Frame Chaining 미적용 |
| **해결책** | 1. 이전 씬 마지막 프레임 추출 2. 다음 씬 첫 프레임으로 사용 |
| **예방** | FRAME_CHAINING.md 가이드 준수 |

## 🔄 워크플로우 문제

### ERR-WF-001: ANCHOR 실패

**증상**: 첫 ANCHOR부터 만족스럽지 않음

| 항목 | 내용 |
|------|------|
| **원인** | 프롬프트 부정확, 도구 선택 오류 |
| **해결책** | 1. MJ --oref 사용 2. 3-5회 반복 생성 3. 최선 선택 후 진행 |
| **결정** | ANCHOR에 30분 이상 소요 시 → 프롬프트 전면 재검토 |

---

### ERR-WF-002: Stage 중단

**증상**: Stage 2에서 실패, 처음부터 다시?

| 항목 | 내용 |
|------|------|
| **원인** | 이전 Stage 결과물 손상, 방향 변경 |
| **해결책** | 1. Checkpoint에서 재개 2. 완료된 Stage 결과물 유지 3. 실패 Stage만 재시도 |
| **예방** | Stage 완료 시 메타데이터 저장 |
