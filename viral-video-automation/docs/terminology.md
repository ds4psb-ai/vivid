# 용어 통일표

> **VIVID AI 영상 자동화 워크샵**
> 팀 내부 공유용 용어 가이드

---

## 핵심 원칙

1. **첫 등장 시** 괄호로 원어 표기, 이후 한글만 사용
2. **한 문장 = 한 정보** 원칙 적용
3. 기술 용어는 **비유**나 **예시**로 설명

---

## 용어 대조표

### 필수 용어

| 기존 | 개선 | 원어 | 설명 |
|------|------|------|------|
| ANCHOR Image | **기준 프레임** | ANCHOR | 캐릭터 얼굴이 가장 잘 보이는 장면. 모든 이미지 생성의 기준점. |
| Visual Rhyme | **시각 대비** | Visual Rhyme | 과거↔현재 장면의 조명, 색감, 분위기 차이 |
| Digital Twin JSON | **나의 프로필** | Digital Twin | AI가 분석한 나의 심리 데이터 파일 |
| RAW 마크다운 | **원본 파일** | RAW | 수정 없이 그대로 저장한 결과물 |
| 오마쥬 | **오마주** | Hommage | 외래어 표기법 통일 (국립국어원 기준) |

### 시간/구조 용어

| 기존 | 개선 | 설명 |
|------|------|------|
| Phase 1-2 | **1막 (과거)** | 회상, 추억, 어린 시절 장면 |
| Phase 3-4 | **2막 (현재)** | 현재 시점, 결말 장면 |
| ANCHOR Phase | **기준 장면** | 영상의 시작점, 캐릭터 소개 장면 |

### 도구/앱 용어

| 기존 | 개선 | 설명 |
|------|------|------|
| Canvas App | **캔버스 앱** | AI Studio에서 ZIP 파일을 실행하는 기능 |
| Flow | **"Flow" 메뉴** | Gemini 앱 내 영상 생성 메뉴 |
| Builder 1 | **Builder 1 (영상 분석기)** | 영상 → 이미지 프롬프트 변환 도구 |
| Builder 2 | **Builder 2 (변주 엔진)** | 분석 결과 → 오마주/변주 생성 도구 |

### 심리 분석 용어

| 기존 | 개선 | 설명 |
|------|------|------|
| 페르소나 | **캐릭터 설정** | 또는 그대로 "페르소나" 유지 가능 |
| 영혼 추출 | **프로필 저장** | JSON 파일 다운로드 기능 |
| 심도 | **분석 깊이** | 대화 진행에 따른 분석 진척도 (0~100%) |

## 문장 단순화 예시

### Before (문제)
```
"Builder 1은 영상을 분석하여 이미지 생성용 프롬프트를 만드는 도구입니다."
```

### After (개선)
```
🎬 Builder 1 = 영상 분석기

영상 넣으면 → 이미지용 명령어 나옴
```

---

### Before (문제)
```
"생성된 JSON 데이터셋은 Builder 2에서 패러디/변주 생성 시 고도화에 사용됩니다."
```

### After (개선)
```
💾 저장한 프로필은 Builder 2에서 사용해요

나의 프로필 + 영상 분석 → 나만의 변주 영상
```
