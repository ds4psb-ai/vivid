## 1.2 FFmpeg 설치

> 영상에서 기준 프레임을 추출할 때 필요해요

### macOS 사용자

```bash
# 1. Homebrew 업데이트
brew update

# 2. FFmpeg 설치
brew install ffmpeg

# 3. 설치 확인
ffmpeg -version
```

> 💡 **팁**: Homebrew가 없다면? [brew.sh](https://brew.sh)에서 먼저 설치하세요

---

### Windows 사용자

☐ [ffmpeg.org/download.html](https://ffmpeg.org/download.html) 접속

☐ Windows 빌드 다운로드 & 압축 해제

☐ 환경변수 PATH에 `ffmpeg/bin` 폴더 추가

<details>
<summary>▶ PATH 설정이 처음이라면 (클릭해서 펼치기)</summary>

1. 시작 → "환경 변수" 검색
2. "시스템 환경 변수 편집" 클릭
3. "환경 변수" 버튼 클릭
4. "Path" 선택 → "편집"
5. "새로 만들기" → ffmpeg 폴더 경로 입력
   예: `C:\ffmpeg\bin`
6. 확인 → 확인 → 확인

</details>

# 🎬 2. 기준 프레임 추출

> 기준 프레임 (ANCHOR) = 모든 이미지 생성의 **기준점**

---

## 2.1 왜 필요한가요?

AI가 영상 속 캐릭터를 일관되게 그리려면 **"이 사람이야!"** 하고 알려줄 기준 이미지가 필요해요.

```
기준 프레임 없이 생성 → 매번 다른 얼굴
기준 프레임 사용 → 같은 캐릭터 유지
```

---

## 2.2 기준 프레임 추출하기

### 첫 번째 프레임 추출

```bash
ffmpeg -i 내영상.mp4 -vf "select=eq(n\,0)" -vframes 1 기준프레임.png
```

> 영상의 맨 첫 장면을 이미지로 저장해요

---

### 특정 시간대 추출 (예: 2.5초 지점)

```bash
ffmpeg -i 내영상.mp4 -ss 00:00:02.500 -vframes 1 기준프레임.png
```

> 💡 **팁**: 얼굴이 가장 잘 보이는 장면을 찾아 그 시간대를 입력하세요

---

## 2.3 좋은 기준 프레임 vs 나쁜 기준 프레임

| ✅ 좋은 기준 프레임 | ❌ 피해야 할 기준 프레임 |
|-------------------|----------------------|
| 얼굴이 정면 또는 3/4 각도 | 뒷모습, 옆모습만 보임 |
| 조명이 균일함 | 역광, 극단적 명암 |
| 표정이 자연스러움 | 과격한 표정 (소리 지르기 등) |
| 해상도가 선명함 | 모션 블러, 흔들림 |

# 🔍 3. Builder 1: 영상 분석기

> 영상 넣으면 → 이미지용 명령어 나옴

---

## 3.1 Builder 1이란?

```
📹 내 영상
    ↓ Builder 1
📝 이미지 생성용 프롬프트
```

**출력 형식 선택 가능:**
- **NanoBanana Pro**: 한글 프롬프트 (기본)
- **Midjourney V7**: 영문 프롬프트 (선택)

---

## 3.2 4단계 워크플로우

### STEP 1: 영상 분석

> 영상을 업로드하면 AI가 자동으로 분석해요

**분석 결과:**
- 📊 **씬 테이블**: 장면별 시간/내용 정리
- 👤 **캐릭터 프로필**: 등장인물 특징
- 🎨 **시각 대비**: 과거↔현재 조명/색감 차이
- 📐 **구도 분석**: 카메라 앵글, 배치

---

### STEP 2: 1막 프롬프트 (과거)

> 회상/추억 장면의 이미지 프롬프트 생성

특징:
- 따뜻한 색감 (세피아, 골드톤)
- 부드러운 조명
- 그레인/빈티지 효과

---

### STEP 3: 2막 프롬프트 (현재)

> 현재/결말 장면의 이미지 프롬프트 생성

특징:
- 선명한 색감 (콜드톤 또는 뉴트럴)
- 깔끔한 조명
- 고해상도 디테일

---

### STEP 4: 원본 파일 다운로드

> 📥 마크다운 파일로 저장

이 파일을 **Builder 2**에 입력으로 사용해요

---

## 3.3 출력 예시

```markdown
## 📊 영상 분석 요약

### 씬 테이블
| Scene | 시간대 | 설명 | 기준 |
|-------|--------|------|------|
| 01 | 00:00~00:01 | 거실에서 케이크 들고 있는 엄마 | ⭐ 기준 프레임 |
| 02 | 00:01~00:02 | 7살 소년의 생일파티 | |
| 03 | 00:02~00:05 | 촛불 끄는 장면 | |
```

# 🔮 4. 바이브 철학관

> AI와 대화하며 **나의 프로필**을 만들어요

---

## 4.1 바이브 철학관이란?

```
💬 AI와 대화
    ↓
🔍 심층 분석 진행
    ↓
💾 나의 프로필 (JSON) 저장
```

저장한 프로필은 Builder 2에서 사용해요
→ 나의 감성이 담긴 변주 영상을 만들 수 있어요

---

## 4.2 시작하기

☐ **Step 1**: AI Studio에서 `vibe-philosophy.zip` 업로드

☐ **Step 2**: 기본 정보 입력
- 이름
- 생년월일 (음력/양력)
- 관상 사진 (선택)
- MBTI (선택)

☐ **Step 3**: "세션 시작" 클릭

☐ **Step 4**: AI와 자연스럽게 대화

---

## 4.3 분석 깊이 시스템

> 대화가 진행될수록 분석이 깊어져요

| 단계 | 깊이 | 내용 |
|------|------|------|
| 🌱 탐색 | 0~25% | 라포 형성, 기본 정보 |
| 🌿 전개 | 26~45% | 표면적 고민 확인 |
| 🌲 잠재의식 | 46~65% | 반응 패턴 분석 |
| 🌳 무의식 | 66~85% | 그림자, 억압된 욕구 |
| 🌴 원형 | 86~95% | 원형 통합 |
| 🏔️ 합성 | 96~100% | 최종 솔루션 |

> 💡 **팁**: 50% 이상 도달하면 "프로필 저장" 버튼이 활성화돼요

---

## 4.4 프로필 저장하기

**50% 이상**에서 "프로필 저장" 버튼 클릭 → JSON 파일 다운로드

```json
{
  "분석깊이": 78,
  "감정키워드": ["그리움", "후회"],
  "주제키워드": ["가족", "어린시절"],
  "깊은신호": ["인정욕구", "분리불안"],
  "원형": "영원한 소년",
  "애착유형": "불안-회피형"
}
```

# 🎭 5. Builder 2: 변주 엔진

> 분석 결과 + 나의 프로필 → **오마주/변주** 생성

---

## 5.1 오마주 vs 변주

| 유형 | 설명 | 예시 |
|------|------|------|
| **오마주** | 원본 존중. 구도/분위기 유지, 캐릭터만 교체 | 생일 케이크 씬 → 내 어린시절로 |
| **변주** | 창의적 변형. 구도 유지, 상황/맥락 변형 | 생일 케이크 → 퇴직 케이크 |

---

## 5.2 입력 데이터

| 필수 | 선택 |
|------|------|
| 📹 원본 영상 | 🔮 나의 프로필 (JSON) |
| 📝 Builder 1 출력 (마크다운) | 💬 베스트 댓글 (최대 5개) |

---

## 5.3 4단계 워크플로우

### STEP 1: 재현성 검증

> Builder 1 출력이 영상과 일치하는지 확인

---

### STEP 2: 오마주 프롬프트 생성

> 원본을 존중하는 이미지 프롬프트

---

### STEP 3: 변주 프롬프트 생성

> 나의 프로필을 반영한 창의적 변형 프롬프트

---

### STEP 4: 원본 파일 다운로드

> 📥 이미지/영상 생성에 바로 사용 가능

## 6.1 NanoBanana Pro (추천)

> 🇰🇷 **한글 프롬프트 지원!**

| 특징 | 설명 |
|------|------|
| 언어 | 한글 프롬프트 OK |
| 해상도 | 4K 이미지 |
| 속도 | 약 3~8초 |
| 강점 | 캐릭터 일관성 우수 |

**접속**: [nanobanana-pro.com](https://nanobanana-pro.com) 또는 AI Studio 내장

### 사용 순서

☐ 레퍼런스 이미지 업로드 (기준 프레임)

☐ Builder 프롬프트 붙여넣기

☐ Generate → 4K 이미지 다운로드

---

## 6.2 Midjourney V7

> 🎨 **예술적 스타일 강점**

| 특징 | 설명 |
|------|------|
| 언어 | 영문 프롬프트 전용 |
| 강점 | 예술적 표현, 스타일 커스터마이징 |

### 핵심 파라미터

```
--iw 2.0      # 이미지 가중치 (높을수록 레퍼런스 충실)
--ar 9:16     # 세로 영상 비율
--v 7         # 버전 7
--cref [URL]  # 캐릭터 레퍼런스
--stylize 250 # 과거 씬 (따뜻하게)
--stylize 400 # 현재 씬 (선명하게)
```
