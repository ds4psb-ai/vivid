## ✅ 반드시 해야 할 것 (MANDATORY)

### 1. 프레임-바이-프레임 분석
- 영상의 **모든 컷 전환 지점**을 감지
- 각 컷의 **첫 번째 프레임**을 정확히 캡처
- 1초 미만의 짧은 컷도 누락 없이 포함

### 2. 시각적 요소 그대로 묘사
| 요소 | 묘사 방법 |
|------|----------|
| 인물 | **영상 속 인물의 포즈, 의상, 표정을 그대로** 묘사. 단, 피부톤/얼굴 특징만 "Korean" 추가 |
| 배경 | **영상에 보이는 그대로** 묘사 (색상, 가구, 소품 위치) |
| 조명 | **영상에 보이는 그대로** 묘사 (밝기, 방향, 그림자) |
| 색감 | **영상의 실제 색조** 묘사 (warm tones, cool tones, desaturated 등) |
| 구도 | **영상의 정확한 카메라 앵글** 묘사 (close-up, wide shot, top-down 등) |

### 3. 🧑 인물 일관성 (CHARACTER CONSISTENCY) - 매우 중요!

**첫 번째 컷에서 각 인물에 대해 상세 프로필을 작성하고, 이후 모든 컷에서 동일하게 사용합니다.**

#### 3-1. Character ID 시스템
영상에 등장하는 각 인물에게 고유 ID를 부여하세요:
- `[CHILD_A]` - 주인공 아이
- `[ADULT_1]` - 첫 번째 어른 (예: 아버지)
- `[ADULT_2]` - 두 번째 어른 (예: 어머니)
- `[ADULT_3]` - 세 번째 어른 (예: 할머니)
- `[ADULT_PRESENT]` - 현재 시점의 성인 주인공
- 등등...

#### 3-2. Character Profile Card (첫 등장 시 작성)
각 인물 첫 등장 시 다음 항목을 상세히 기록:

```
[CHARACTER PROFILE: CHILD_A]
- Ethnicity: Korean (swap from original)
- Apparent Age: (영상에서 보이는 대로, 예: young child, approximately 6-8 years old)
- Hair: (색상, 길이, 스타일 - 영상 그대로)
- Face Shape: (영상에서 보이는 대로)
- Eye Type: (영상 기반 + Korean 특성 반영: single eyelid 또는 double eyelid)
- Expression: (현재 컷의 표정)
- Clothing: (정확한 색상, 스타일, 패턴)
- Pose/Position: (현재 컷의 포즈)
- Distinguishing Features: (특이사항)
```

#### 3-3. 이후 컷에서의 활용
- 같은 인물이 다른 컷에 등장할 때 **Profile Card를 그대로 참조**
- 표정/포즈만 해당 컷에 맞게 변경
- **절대로 의상, 헤어스타일, 얼굴 특징을 바꾸지 않음**

#### 3-4. 과거 ↔ 현재 인물 연결
과거의 아이와 현재의 성인이 같은 인물이라면:
```
[CHARACTER LINK]
CHILD_A (past) → ADULT_PRESENT (present)
Shared Features: same eye shape, same facial structure (aged), same hairstyle texture
```

### 4. 🎨 색감 일관성 (LUT/Color Grade Consistency)
- **모든 과거 씬**: 동일한 색감 키워드 세트 사용 (예: warm amber tint, soft grain, lifted blacks)
- **모든 현재 씬**: 동일한 색감 키워드 세트 사용 (예: cool teal, high contrast, sharp digital)
- 각 프롬프트 마지막에 **[COLOR CONSISTENCY KEY]** 명시
