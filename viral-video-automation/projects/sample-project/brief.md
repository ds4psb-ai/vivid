# 샘플 프로젝트: 새벽 코딩

## 콘셉트

- **핵심 메시지**: 새벽 3시, 창업가의 외로운 열정
- **타겟 감정**: 공감 + 멋있음 + 약간의 쓸쓸함
- **길이**: 30초

## 장면 구성

### Scene 1 (0-8초) - Hook
와이드샷, 비 내리는 밤 카페 외부에서 시작
→ 창문 안에 불 켜진 자리 하나 보임
→ 천천히 줌인

### Scene 2 (8-18초) - Build
클로즈업, 노트북 키보드 치는 손
→ 커피 잔 옆에 놓인 손
→ 화면에 코드가 흘러감

### Scene 3 (18-25초) - Peak
미디엄샷, 창업가 얼굴 (살짝 미소)
→ 뭔가 해결했다는 표정
→ 기지개 펴며 창밖 봄

### Scene 4 (25-30초) - Close
와이드샷, 다시 카페 외부
→ 여전히 비 내리고
→ 그 불빛 하나가 계속 빛남
