# ✅ QA 체크리스트 (생성 후 검증)

> **사용법**: 이미지/영상 생성 후 이 체크리스트로 검증
> **목표**: 재생성 최소화, 미세조정으로 해결

---

## 🎨 이미지 생성 후

### 인물 체크
- [ ] 모든 인물이 한국인으로 보이는가?
- [ ] 배경 인물도 한국인 피부톤인가?
- [ ] 아이 얼굴이 ANCHOR와 일치하는가?
- [ ] 의상 색깔이 원본과 동일한가?

### 구도 체크
- [ ] 카메라 앵글이 원본과 동일한가?
- [ ] 인물 위치가 원본과 동일한가?
- [ ] 배경 요소가 적절한가?

### 조명 체크
- [ ] 색온도가 맞는가? (3200K = 따뜻 / 6500K = 차가움)
- [ ] 광원 방향이 맞는가?

### 시대 체크
- [ ] 1990s 씬에 스마트폰이 없는가?
- [ ] 2020s 씬에 적절한 현대 요소가 있는가?

---

## 🎬 영상 생성 후 (Kling)

- [ ] 캐릭터 얼굴이 유지되는가?
- [ ] 동작이 자연스러운가?
- [ ] 조명이 일관되는가?
- [ ] 물리 법칙이 지켜지는가? (중력, 충돌)

---

## 🎤 영상 생성 후 (Veo - 대사 있음)

- [ ] 립싱크가 맞는가?
- [ ] 파열음(ㅂ,ㅍ,ㅁ)에서 입술이 닫히는가?
- [ ] 표정이 대사 감정과 일치하는가?
- [ ] 24fps 유지되는가?

---

## 🛠️ 문제 해결 (재생성 안하고!)

| 문제 | 해결법 |
|------|--------|
| 배경 인물 서양인 | --no에 `caucasian skin in background` 추가 |
| 의상 색깔 다름 | 프롬프트에 색깔 더 강조 |
| 테이블에 케이크 2개 | --no에 `cake on table, duplicate cake` 추가 |
| 조명 안맞음 | 색온도(K) 명시 추가 |
| 스마트폰 나옴 | --no에 `smartphones` 추가 |

---

## 📊 성공 기준

### 이미지
| 항목 | 기준 |
|------|------|
| 인물 일관성 | ANCHOR와 80% 이상 유사 |
| 구도 정확도 | 원본과 90% 이상 일치 |
| 인종 정확도 | 100% 한국인 |

### 영상
| 항목 | 기준 |
|------|------|
| 얼굴 유지 | 프레임 전체 일관 |
| 립싱크 (Veo) | 음절 ±0.1초 이내 |
| 물리 정확도 | 왜곡 없음 |
