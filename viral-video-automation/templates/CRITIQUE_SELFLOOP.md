# 🔄 Critique Self-Loop Guide

> **Purpose**: AI 자동 평가 → 개선 제안 → 재생성 루프
> **Version**: 2026 (티키타카 철학 기반)

---

## 🎯 Self-Loop vs 기존 방식

### 기존 (수동 평가)

```
1. 생성
2. 사용자가 직접 평가
3. 사용자가 수정 요청
4. 재생성
```

### Self-Loop (AI 자동 평가)

```
1. 생성
2. AI가 자동 평가 (CRITIQUE 템플릿 기반)
3. AI가 개선 프롬프트 제안
4. 사용자 승인 후 재생성
        ↓
   Human-in-the-Loop 유지!
```

---

## 🔧 Self-Loop 워크플로우

```
Step 1: Generate
        ↓
Step 2: AI Self-Critique
        "이 이미지를 CRITIQUE_IMAGE.md 기준으로 평가해줘"
        ↓
Step 3: AI Improvement Suggestion
        "평가 기반으로 개선된 프롬프트 제안해줘"
        ↓
Step 4: Human Approval
        사용자: "좋아, 이걸로 재생성해줘" / "아니, 이 부분 수정해"
        ↓
Step 5: Regenerate or Accept
```

## 📋 Self-Critique 프롬프트

### 이미지 평가 요청

```
[생성된 이미지 첨부]

이 이미지를 아래 기준으로 평가해줘:

### 평가 기준
1. 프롬프트 준수: 의도한 대로 생성됐나?
2. 캐릭터 일관성: ANCHOR와 얼굴 일치?
3. 해부학: 손/얼굴 왜곡?
4. 기술적 품질: 아티팩트, 해상도?
5. 스타일: 조명, 색감 일치?

### 출력 형식
{
  "verdict": "PASS/REVISE/REJECT",
  "score": 0-100,
  "issues": [...],
  "improvements": [...]
}
```

### 영상 평가 요청

```
[생성된 영상 첨부]

이 영상을 아래 기준으로 평가해줘:

### 평가 기준
1. Beat Timing: 지시한 타이밍대로?
2. 모션 품질: 자연스러운 동작?
3. 캐릭터 일관성: 프레임 전체 유지?
4. 아티팩트: 모핑/텔레포트?
5. 카메라: 1 Camera 룰 준수?

### 출력 형식
{
  "verdict": "PASS/REVISE/REJECT",
  "score": 0-100,
  "issues": [...],
  "parameter_adjustments": {...}
}
```

## 📝 개선 제안 프롬프트

### 이미지 개선 요청

```
위 평가를 기반으로 개선된 프롬프트를 제안해줘.

### 규칙
1. 발견된 문제만 수정
2. 잘 되는 부분은 유지
3. --no 파라미터 추가/수정
4. 변경 이유 설명

### 출력 형식
**변경 사항**:
- [변경1]: [이유]
- [변경2]: [이유]

**개선된 프롬프트**:
[COPY 가능한 프롬프트]
```

### 영상 개선 요청

```
위 평가를 기반으로 개선된 프롬프트와 파라미터를 제안해줘.

### 규칙
1. Beat Timing 수정 (필요시)
2. Creativity/Motion 파라미터 조정
3. Negative prompt 추가
4. 변경 이유 설명

### 출력 형식
**변경 사항**:
- [변경1]: [이유]

**개선된 프롬프트**:
[COPY 가능한 프롬프트]

**파라미터 변경**:
| 항목 | 이전 | 변경 |
```

## 🔑 Human-in-the-Loop 체크포인트

### 자동 승인 (PASS)

```
AI: "Score 95, PASS. 바로 사용 가능."
User: "OK" or 무응답 → 다음 진행
```

### 승인 필요 (REVISE)

```
AI: "Score 70, REVISE. 손 왜곡 발견. 개선 프롬프트:"
User: "좋아, 재생성해" or "아니, 손은 괜찮아"
```

### 전면 재작성 (REJECT)

```
AI: "Score 40, REJECT. 캐릭터 완전 불일치. 처음부터:"
User: 반드시 확인 후 진행
```

## ✅ Self-Loop 체크리스트

루프 전:
- [ ] 원본 프롬프트 보관
- [ ] CRITIQUE 기준 준비

루프 중:
- [ ] AI 평가 결과 확인
- [ ] 개선 제안 검토
- [ ] 필요시 수정 지시

루프 후:
- [ ] 성공 패턴 기록 (CRITIQUE_LOG.md)
- [ ] 실패 패턴 기록 (→ --no 추가)

## 💡 팁

1. **3회 이상 실패** → 프롬프트 전면 재검토
2. **반복 문제** → 템플릿 수준에서 수정
3. **AI도 틀림** → Human 최종 판단 필수
4. **로그 기록** → 같은 실수 반복 방지
