## 🔑 프롬프트 공식

### 단일 레퍼런스
```
이 이미지를 기반으로:
- 구도, 조명, 배경을 정확히 유지
- 모든 인물을 한국인으로 교체
- 옷 색깔과 위치는 원본 그대로

스타일: 1990년대 따뜻한 홈비디오 느낌, Kodak Portra 400 필름 그레인
```

### 복수 레퍼런스 (구도 + 캐릭터)
```
**Image 1 (구도용)**: [scene.png]
**Image 2 (얼굴용)**: [anchor.png]

Image 1에서 복사:
- 정확한 구도와 인물 배치
- 조명 방향과 색온도 (3200K 텅스텐)
- 옷 색깔 (아빠: 초록 셔츠, 엄마: 빨간 스웨터)
- 배경 (1990년대 한국 아파트)

Image 2에서 복사:
- 아이 얼굴 (단발 머리, 홑꺼풀, 수줍은 미소)

교체 대상:
- 모든 인물 → 한국인 (한국인 피부톤, 눈 모양)
- 부모도 한국인 (흐릿해도!)

금지 요소: 서양인 특징, 백인 피부, 금발, 파란 눈
```

## 📝 씬별 프롬프트

### Scene 1: The Arrival
```
**Image 1 (구도)**: [scene01_arrival.png]
**Image 2 (얼굴)**: [ANCHOR.png]

Image 1의 구도를 정확히 유지:
- 역삼각형 구성 (아이 중앙 하단, 부모가 좌우에서 감싸는 형태)
- 따뜻한 텅스텐 조명 (3200K)
- 1990년대 한국 아파트 배경

Image 2에서 아이 얼굴을 복사해서 중앙의 아이에 적용

모든 인물을 한국인으로 교체:
- 아이: Image 2 얼굴 사용
- 부모: 한국인 (같은 옷 색깔 유지)
- 배경 친척: 한국인

금지: 서양인, 백인 피부, 현대 가구, LED 조명, 스마트폰
```

### Scene 3: The Clapping
```
**Image 1 (구도)**: [scene03_clapping.png]
**Image 2 (얼굴)**: [ANCHOR.png]

Image 1의 삼각형 구도 유지:
- 아이 중앙, 부모가 뒤에서 아치 형태로 박수
- 박수 치는 손 위치와 모션 블러 유지
- 따뜻한 텅스텐 조명

Image 2에서 아이 얼굴 복사

모든 인물을 한국인으로:
- 아이: Image 2 얼굴
- 엄마: 박수 치는 한국 여성 (빨간 스웨터)
- 아빠: 박수 치는 한국 남성 (초록 셔츠)

분위기: 진심 어린 기쁨, 가족의 따뜻함

금지: 서양인, 스마트폰, 차가운 조명
```

### Scene 6: Digital Isolation
```
**Image 1 (구도)**: [scene06_lonely.png]

Image 1의 구도 유지하되 분위기만 반전:
- Scene 3과 같은 삼각형 구도
- 하지만 박수 대신 스마트폰 들고 있음
- 차가운 LED 조명 (6500K)
- 칠흑같이 어두운 배경

모든 인물을 한국인으로:
- 중앙: 28세 한국 남성 (댄디컷, 홑꺼풀, 공허한 미소)
- 주변: 스마트폰 플래시 켜고 촬영하는 한국인 친구들

분위기: 고립감, "죽은 눈", 디지털 소외

금지: 따뜻한 조명, 촛불, 진심 어린 행복, 박수
```
