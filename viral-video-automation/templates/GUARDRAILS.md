# 🛡️ 4-Layer Guardrails Checklist

> **Purpose**: 문제 조기 발견으로 복구 비용 감소
> **Version**: 2026-02
> **Philosophy**: Human-in-the-Loop 강화

---

## 📊 4개 레이어 개요

```
┌─────────────────────────────────────────┐
│ Layer 4: HUMAN APPROVAL                 │ ← 최종 판단
├─────────────────────────────────────────┤
│ Layer 3: OUTPUT VALIDATION              │ ← 결과물 체크
├─────────────────────────────────────────┤
│ Layer 2: MODEL GUARDRAILS               │ ← 도구/파라미터
├─────────────────────────────────────────┤
│ Layer 1: DATA GUARDRAILS                │ ← 입력 검증
└─────────────────────────────────────────┘
         ↑ 문제 발생 위치가 낮을수록 복구 비용 ↓
```

---

## 📋 Layer 1: DATA GUARDRAILS

> 입력 데이터 검증 - 시작 전 체크

### 공통

- [ ] 원본 영상 준비됨
- [ ] 키프레임 추출 완료
- [ ] ANALYSIS.md 작성됨
- [ ] PROFILES.md 확정됨

### 이미지 생성 전

- [ ] ANCHOR 이미지 존재
- [ ] 프롬프트에 ALL PEOPLE 규칙 적용
- [ ] Multi-Entity 레퍼런스 준비 (의상, 배경)
- [ ] Negative prompt 포함
- [ ] 레퍼런스 이미지 해상도 1080p+

### 영상 생성 전

- [ ] 이미지 최종 확정 (selected/)
- [ ] Beat Timing 패턴 작성
- [ ] 이전 씬 마지막 프레임 추출 (Frame Chaining)

---

## 📋 Layer 2: MODEL GUARDRAILS

> 도구 및 파라미터 검증

### 도구 선택

- [ ] 씬에 맞는 도구 선택 (SYSTEM_GUIDE.md 참조)
  - ANCHOR → Midjourney
  - 다인물 → NanoBanana
  - 대사 없음 → Kling
  - 시네마틱 → Sora

### 파라미터 범위

**이미지 (Midjourney)**
- [ ] --iw: 1.5-2.5
- [ ] --cw: 50-100
- [ ] --stylize: 200-400

**영상 (Kling)**
- [ ] Creativity: 0.5-0.7 (안정적)
- [ ] Duration: 최소 5초
- [ ] Mode: Standard (안정) / Professional (품질)

**영상 (Sora)**
- [ ] Duration: 10-25초
- [ ] Resolution: 1080p 이상

## 📋 Layer 3: OUTPUT VALIDATION

> 결과물 자동 체크 (Critique 기반)

### 이미지 체크 (CRITIQUE_IMAGE.md)

- [ ] 프롬프트 준수 (의도대로 생성됨)
- [ ] 캐릭터 일관성 (ANCHOR와 일치)
- [ ] 해부학 정확 (손, 얼굴 왜곡 없음)
- [ ] 기술 품질 (아티팩트, 해상도)
- [ ] 스타일 일치 (조명, 색감)

### 영상 체크 (CRITIQUE_VIDEO.md)

- [ ] Beat Timing 준수
- [ ] 모션 품질 (자연스러운 동작)
- [ ] 캐릭터 일관성 (프레임 전체)
- [ ] 아티팩트 없음 (모핑, 텔레포트)
- [ ] 1 Camera 1 Action 룰

### Self-Loop 판정

| 판정 | 조건 | 다음 행동 |
|------|------|----------|
| PASS | Score 85+ | → Layer 4 진행 |
| REVISE | Score 60-84 | → 수정 후 재생성 |
| REJECT | Score < 60 | → 프롬프트 재검토 |

---

## 📋 Layer 4: HUMAN APPROVAL

> 최종 창작 판단

### 체크포인트

- [ ] 창작 의도와 일치
- [ ] 감정/분위기 적절
- [ ] 전체 흐름에서 자연스러움
- [ ] 최종 승인

### 결정

| 결정 | 다음 행동 |
|------|----------|
| ✅ 승인 | 다음 Stage 진행 |
| 🔄 수정 | 피드백 반영 후 Layer 3 재시작 |
| ❌ 거부 | Layer 1부터 재검토 |

## 🔄 워크플로우 통합

```
┌─────────────────────────────────────────┐
│ STAGE 시작                              │
└──────────────┬──────────────────────────┘
               ↓
┌──────────────┴──────────────────────────┐
│ Layer 1: Data 체크                      │
│ FAIL → 데이터 보완                       │
└──────────────┬──────────────────────────┘
               ↓
┌──────────────┴──────────────────────────┐
│ Layer 2: Model 체크                     │
│ FAIL → 도구/파라미터 수정               │
└──────────────┬──────────────────────────┘
               ↓
┌──────────────┴──────────────────────────┐
│ 생성 실행                               │
└──────────────┬──────────────────────────┘
               ↓
┌──────────────┴──────────────────────────┐
│ Layer 3: Output 체크                    │
│ REVISE → 수정 후 재생성                 │
│ REJECT → Layer 1/2 재검토               │
└──────────────┬──────────────────────────┘
               ↓
┌──────────────┴──────────────────────────┐
│ Layer 4: Human 승인                     │
│ PASS → 다음 Stage                       │
│ FAIL → 피드백 반영                      │
└─────────────────────────────────────────┘
```
